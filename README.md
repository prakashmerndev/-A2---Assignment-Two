# 🥤 Cold Drink Shop Website

A simple and attractive Cold Drink Shop website built using **HTML and CSS**.

This project was created to practice and understand CSS layout concepts, especially **Position** and **Flexbox**.

## 🚀 Features

- 🥤 Cold drink shop landing page
- 🎨 Attractive UI using HTML & CSS
- 📦 Product/card layout using Flexbox
- 📍 Element positioning using CSS Position
- ✨ Simple and beginner-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Practiced

### 1. Display Flex

Used `display: flex` to:

- Arrange elements horizontally
- Create flexible layouts
- Align and distribute content
- Build product/card sections

### 2. CSS Position

Used CSS positioning such as:

- `position: relative`
- `position: absolute`
- `position: fixed`

These helped in placing elements at specific positions on the webpage.
